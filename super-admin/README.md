# Trip Wheels Super Admin Dashboard

Trip Wheels Super Admin is the private operations console used by the Trip Wheels team to oversee publisher verifications, vehicle moderation, booking workflows, customer disputes, platform watchlists, business settings, audit trails, and key performance metrics.

## Key Features

- **Operational Overview**: Real-time decision queues for pending publisher document verifications, vehicle moderation, and customer disputes.
- **Operational Notices**: Live alerts for at-risk bookings, pending pickups in the next 24 hours, and unconfirmed vehicles.
- **Trip Demand & Velocity Charting**: Visual analytics for booking trends and completed trips.
- **Responsive Layout**: Powered by Shadcn UI with light/dark theme support, mobile navigation drawer, and search.
- **Backend API Integration**: Direct integration with the Trip Wheels backend API via `/api/v1` proxy with fallback support.

## Available Scripts

- `npm run dev`: Starts the Next.js development server.
- `npm run build`: Compiles the application and generates optimized production bundles.
- `npm run start`: Starts the Next.js production server.
